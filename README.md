# SFOOD IT Editor

사내 직원 전용 문서 작성·게시 도구. sfood-it-tech-blog(Viewer) 저장소에서 분리되었다.

## 🛠️ 최초 1회 운영 작업

애플리케이션을 배포하기 전에, 운영자가 Confluence에서 아래 작업을 **수동으로 한 번** 완료해야 한다. 이 작업이 끝나지 않으면 개인 폴더 생성과 문서 목록 조회가 오류로 실패한다.

1. `CONFLUENCE_SPACE_KEY`로 지정한 Confluence Space의 **홈페이지 직속 하위**에 다음 두 페이지를 만든다. 애플리케이션은 이 두 페이지를 pageId가 아닌 **제목 완전 일치**로 찾으므로 제목을 정확히 입력해야 한다.
   - `초안` — 작성 중인 문서(개인 폴더)가 놓이는 루트
   - `게시됨` — 게시된 문서가 옮겨지는 루트
2. `초안` 페이지에 Confluence 페이지 제한(Page restriction)을 설정해, `CONFLUENCE_EMAIL`/`CONFLUENCE_API_TOKEN`으로 구성한 **서비스 계정만** 읽기(read)·수정(update) 할 수 있도록 제한한다. 이 제한이 하위 페이지로 상속되어 다른 직원에게 초안이 노출되지 않는다.
3. `게시됨` 페이지에는 제한을 설정하지 않는다. 게시 시 문서가 이 루트로 이동하면서 제한이 해제되어 Space 기본 권한(구성원 전체 공개)으로 공개된다.

환경변수 설정은 `.env.example`을 참고한다. 두 루트 페이지의 pageId를 위한 환경변수는 없다.
