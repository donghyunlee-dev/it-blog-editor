## 문제 → 조치 → 재검증
1. **원인**: "검색어로 폴더의 문서가 전부 가려져도, 실제로 문서가 있는 폴더는 빈 폴더 안내를 보여주지 않는다"를 검증하려던 첫 시도에서, 검색어를 어떤 문서와도 일치하지 않는 문자열로 줬더니 `filteredDocuments.length`가 전체적으로 0이 되어 사이드바가 폴더 트리 자체를 그리지 않고 최상위 "조건에 맞는 문서가 없습니다." `EmptyState`로 완전히 대체해버렸다 — 그래서 "문서 있음" 폴더 버튼 자체를 찾지 못해 테스트가 실패했다.
   **조치**: 검색어를 다른 폴더(하위 문서)의 제목과는 일치하되 "문서 있음" 폴더의 문서(회의록)와는 무관한 문자열로 바꿔, 전체 목록은 비지 않으면서(트리가 계속 그려짐) 그 폴더 하나만 필터로 가려지는 실제 시나리오를 재현했다.
   **재검증**: 통과.
