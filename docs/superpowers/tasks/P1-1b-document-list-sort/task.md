# P1-1b: 문서 목록 정렬 옵션(최신순/제목순)

## 배경
2026-08-27 [프로덕션 준비도 감사](https://claude.ai/code/artifact/87302c07-68d6-42ed-8712-9345547cb659)에서 P1로 지적된 항목. `EditorSidebar.tsx`는 `listDocuments()`가 반환한 순서(초안 목록 뒤에 게시 목록을 이어붙인, Confluence API가 준 순서)를 그대로 보여줄 뿐 정렬 옵션이 없다.

## 수용 기준 (Acceptance Criteria)
- [ ] 사이드바에 정렬 옵션(최신순/제목순)을 고를 수 있는 드롭다운을 추가한다(`@sfood/ui`의 `Select` 사용).
- [ ] 기본값은 "최신순"이다.
- [ ] "최신순"은 `updatedAt` 내림차순(가장 최근에 수정한 문서가 위)으로 정렬한다.
- [ ] "제목순"은 제목을 한글 로케일 기준으로 오름차순 정렬한다.
- [ ] 정렬은 태그 필터·검색어 필터가 적용된 **뒤에** 이루어진다 — 필터링된 결과를 정렬해서 보여준다.
- [ ] 문서가 없으면(빈 상태) 정렬 드롭다운도 보여주지 않는다(검색 입력과 같은 조건).
