# P1-1a: 사이드바 검색을 태그까지 확장 — 구현 결과 보고서

## 구현 내용
- `EditorSidebar.tsx`의 검색 필터를 "제목 포함" 단독에서 "제목 OR 태그 포함"으로 바꿨다 — `DocumentSummary.tags`가 이미 클라이언트에 있어 추가 네트워크 호출 없이 가능했다.
- 태그 필터 칩(`activeTag`)과 검색어 필터는 계속 AND로 함께 적용된다(기존 동작 유지).
- 검색 입력의 `sr-only` 라벨을 "문서 제목 검색" → "문서 제목·태그 검색"으로 갱신했다.
- **본문(문서 내용) 검색은 이번에 구현하지 않았다** — 코드를 조사해보니 `listDocuments()`가 이미 문서마다 태그를 별도 조회하는 N+1 패턴이라(`api-spec.md`에 명시된 기존 트레이드오프), 본문까지 포함하려면 그 비용을 사실상 두 배로 늘리게 된다. 이는 P0-5a/P1-1c가 이미 다루는 "문서 수 증가에 따른 성능" 문제와 같은 종류라, 임의로 구현 방식을 정하지 않고 [Issue #7](https://github.com/sfood-pioneer-1st/sfood-it-editor/issues/7)로 분리해 결정을 받기로 했다.
