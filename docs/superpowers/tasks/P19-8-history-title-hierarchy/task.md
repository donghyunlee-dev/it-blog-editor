# P19-8: 문서 이력 화면 상단 시각적 위계 수정 (문서 제목 ↔ "문서 이력")

## 배경
P19-7에서 문서 제목을 상단에 추가했지만, 구현 순서가 "제목(작은 라벨) → 문서 이력(큰
제목)"이라 실제 화면에서는 "문서 이력"이 폰트 크기·굵기 때문에 제목처럼 읽히고, 정작
어떤 문서인지 알려주는 문서 제목은 작은 라벨처럼 묻혀 보였다. 스크린샷으로 확인한 사용자
재지적 — "이게 괜찮아 보여? 제목 위치나 폰트를 봐봐. 어떤 게 제목같아 보여?" — 스스로도
"문서 이력"이 제목처럼 보인다고 확인함.

## 수용 기준 (Acceptance Criteria)
- [x] 문서 제목이 가장 눈에 띄는 요소(큰 제목, `h1`)로 표시된다.
- [x] "문서 이력"은 그 위의 작은 라벨로 낮춰, 화면 성격을 보조적으로만 안내한다.
- [x] 제목이 없을 때의 대체 문구("(제목 없음)")는 그대로 유지한다.

## 결정이 필요한 사항
없음 — 시각적 위계(폰트 크기·굵기가 큰 쪽이 "제목"으로 읽힌다)는 디자인 결정이 필요한
문제가 아니라 일반적인 타이포그래피 원칙이다.

## 범위 밖
없음 — 순수 마크업 순서/스타일 교정.
