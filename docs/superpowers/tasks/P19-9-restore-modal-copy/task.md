# P19-9: 복원 확인 Modal 문구·버튼 가독성 개선

## 배경
사용자가 실제 렌더링된 복원 확인 Modal 스크린샷을 보고 지적 — "사람이 읽기 편할까?
복원확인 보다는 확인이 낫지 않을까?" 기존 문구는 3가지 다른 정보(동작 설명·저장 안 한
변경사항 경고·문서 링크 카드 한계)를 한 문단에 몰아 써 한눈에 읽기 어려웠고, 버튼
라벨("복원 확인")도 Modal 제목("버전으로 복원")과 겹쳐 장황했다.

## 수용 기준 (Acceptance Criteria)
- [x] 안내 문구를 항목별로 문단을 나눠 한눈에 읽히게 한다.
- [x] 확인 버튼 라벨을 "복원 확인"에서 "확인"으로 바꾼다.

## 결정이 필요한 사항
없음 — 사용자가 대화에서 버튼 라벨 변경을 직접 제안·확인함.

## 범위 밖
없음.
