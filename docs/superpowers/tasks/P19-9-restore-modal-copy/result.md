# P19-9: 복원 Modal 문구 개선 — 구현 결과

## 구현 내용
- 복원 확인 Modal 본문을 `flex flex-col gap-2`로 감싼 문단 3개로 분리 — (1) 무엇을
  덮어쓰는지·비파괴적이라는 점, (2) 저장 안 한 변경사항 경고, (3) 문서 링크 카드 한계.
- 확인 버튼 라벨을 "복원 확인" → "확인"으로 변경(진행 중 표시는 "복원 중..." 유지).

## 자체 검토 (Self-Review)
### 긍정 사항
- 사용자가 실제 렌더링된 화면을 보고 준 구체적 피드백을 그대로 반영해, 실사용
  가독성을 검증된 상태로 개선했다.

### 주의사항
- "확인"은 다른 화면(삭제 확인 등)의 "{동작} 확인" 관례와 다르다 — 사용자가 이 Modal에
  한해 명시적으로 요청한 것이라 다른 확인 Modal에는 일반화하지 않았다.
