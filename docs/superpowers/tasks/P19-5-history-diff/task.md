# P19-5: 문서 이력에서 버전 간 변경 내용(diff) 보기

## 배경
P19-4에 이어 사용자가 확인한 3가지 이력 확장 중 두 번째(대화, 2026-09-18). Confluence
레거시 API(`GET /rest/api/content/{id}?status=historical&version={n}&expand=body.storage`)로
과거 버전의 저장 형식(storage HTML) 본문을 실제로 받아올 수 있음을 실제 인스턴스로
확인했다. 이 작업은 그 본문을 활용해 "이 버전에서 무엇이 바뀌었는지"를 보여준다.

## 수용 기준 (Acceptance Criteria)
- [ ] 이력 목록의 각 버전 행에서 "변경 내용 보기"(또는 펼치기) 조작으로, 그 버전과 바로
      이전 버전 사이의 차이를 보여준다(첫 번째 버전은 "이전 버전 없음"으로 처리).
- [ ] diff는 순수 텍스트 기준(서식·구조가 아니라 내용 위주)으로 추가/삭제된 부분을
      구분해 보여준다 — 리치 텍스트 구조 diff(표·이미지 위치 변경 등)는 범위 밖이다.
- [ ] 과거 버전 본문 조회 API 호출 실패(예: 그 사이 완전히 삭제된 초기 버전 등 예외적인
      경우)는 에러 없이 "이 버전의 변경 내용을 불러올 수 없습니다" 같은 안내로 처리한다.
- [ ] 읽기 전용 범위(P1-2a)는 유지 — 이 작업도 보기 기능만 추가한다.

## 결정이 필요한 사항
없음 — "순수 텍스트 diff, 바로 이전 버전과 비교"로 범위를 좁혀 진행한다(사용자가
"작업 크기" 질문에서 diff를 "중간 작업"으로 확인한 답변을 근거로, 가장 비용이 적게
드는 텍스트 기준 diff로 시작). 구조적 diff가 필요하면 별도 요청 시 확장한다.

## 범위 밖
- 리치 텍스트 구조(표·이미지·서식) 수준의 diff — 텍스트 diff만 다룬다.
- diff에서 특정 변경 사항만 골라 되돌리는 기능(부분 복원) — P19-6은 버전 전체 복원만
  다룬다.
