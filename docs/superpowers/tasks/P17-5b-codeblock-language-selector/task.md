# P17-5b: 코드 블록 언어 선택 UI

## 배경
사용자 지적("코드 블록에서 편집이 불편함") 중 "언어 선택" 항목. 지금까지는
lowlight가 코드 내용을 보고 자동으로 언어를 추정해 강조했는데(P1-7c), 짧거나
모호한 코드에서는 추정이 틀릴 수 있고 사용자가 직접 바로잡을 방법이 없었다.

## 수용 기준 (Acceptance Criteria)
- [x] 코드 블록마다 언어를 고를 수 있는 드롭다운이 (블록 오른쪽 위에) 보인다.
- [x] 드롭다운 목록은 이 프로젝트가 이미 쓰는 lowlight `common` 번들에 등록된 언어
      (`lowlight.listLanguages()`)로 채워진다 — 번들 밖 언어 추가는 범위 밖.
      "자동 감지"(기존 동작 유지) 항목도 첫 번째로 있다.
- [x] 언어를 고르면 그 언어로 강제 강조(`lowlight.highlight(language, text)`)되고,
      "자동 감지"로 되돌리면 기존처럼 `highlightAuto()`로 돌아간다.
- [x] 고른 언어는 문서 데이터(`codeBlock` 노드의 `language` attrs)에 저장돼 문서를
      다시 열어도 유지된다 — 이미 스키마에 있던 필드를 그대로 쓰므로 별도 마이그레이션
      불필요.
- [x] 기존 문법 강조(P1-7c)·Tab 들여쓰기(P17-5a) 동작은 그대로 유지된다(회귀 없음).

## 결정이 필요한 사항
없음 — "lowlight가 이미 지원하는 언어 목록에서 고르게 한다"는 방식 자체가 유일하게
합리적인 범위이고 번들 확장 요청도 없었다.

## 범위 밖
- lowlight `common` 번들 밖 언어를 추가로 등록하는 것(더 큰 번들 크기 트레이드오프가
  있어 별도 요청 필요).
- 코드 블록 복사 버튼(P17-5c, 별도 작업 — 이번에 추가한 언어 선택 드롭다운과 같은
  코드 블록 헤더 영역에 함께 놓일 예정).
