# P17-5a: 코드 블록 Tab 들여쓰기 지원

## 배경
사용자 지적: "코드 블록에서 편집이 불편함. 탭 안되고, 언어 선택, 코드 복사 기능 등이
없음." 이 중 Tab 들여쓰기 항목을 먼저 다룬다(언어 선택은 P17-5b, 복사 버튼은 P17-5c로
별도 진행).

조사 결과: `RichTextEditor.tsx`의 `CodeBlockLowlight.configure({ lowlight })`가
`enableTabIndentation`을 켜지 않았다(기본값 `false`). `@tiptap/extension-code-block`의
Tab/Shift-Tab 핸들러는 이미 구현돼 있지만(`node_modules` 확인) 이 플래그가 꺼져 있으면
`return false`로 무시되고, 브라우저 기본 동작(다음 포커스 가능 요소로 이동)이 그대로
실행돼 코드 블록 밖으로 포커스가 빠져나간다.

## 수용 기준 (Acceptance Criteria)
- [x] 코드 블록 안에서 커서가 있을 때 Tab을 누르면 그 자리에 들여쓰기(공백)가 삽입되고,
      포커스가 에디터 밖으로 빠지지 않는다.
- [x] Shift-Tab을 누르면 내어쓰기(선행 공백 제거)가 동작한다 — 라이브러리 기본 구현을
      그대로 사용(옵션 하나로 Tab/Shift-Tab 둘 다 함께 켜짐).
- [x] 코드 블록 밖(일반 문단 등)에서는 기존과 동일하게 Tab이 코드 블록 관련 동작을
      하지 않는다(라이브러리가 이미 `$from.parent.type !== this.type`으로 코드 블록
      안일 때만 처리하도록 되어 있음 — 회귀 없이 그대로 유지).
- [x] 들여쓰기 폭(`tabSize`)은 라이브러리 기본값(4칸)을 그대로 쓴다 — 별도로 정할 값
      없음.

## 결정이 필요한 사항
없음 — 이미 구현된 라이브러리 옵션을 켜는 것뿐이라 정할 값이 없다.

## 범위 밖
- 코드 블록 언어 선택 UI(P17-5b), 복사 버튼(P17-5c) — 각각 별도 작업.
- `tabSize`를 사용자가 바꿀 수 있게 하는 설정 UI(요청받지 않음, 기본값 4칸으로 충분).
