# P5-5: 계정 표시 형식 통일

## 배경
- Phase 5(사용자 계정 관리)의 다섯 번째 항목이자 마지막 UI 항목. 이름·팀 온보딩(P5-2)이 끝났는데도 화면에는 여전히 이메일만 표시되고 있다 — 원래 요구사항("계정은 이름(메일) 이런 구조로 보이게 해야 해")을 마무리한다.
- 관련 문서: [prd.md의 Phase 5](../../../product/prd.md#-단계별-개발-계획)(P5-5)

## 수용 기준 (Acceptance Criteria)
- [ ] 계정을 표시하던 위치(사이드바 하단, 접속 차단 안내 화면)가 이름이 있으면 "이름(이메일)" 형식으로 보인다.
- [ ] 이름이 없는 계정(이론상 `accountMeta`가 아직 없거나 온보딩 전인 경우)은 기존처럼 이메일만 표시한다 — 하위 호환.
- [ ] `AccountInfoModal`의 "이메일" 필드, 환영 페이지(`/welcome`)의 "이 계정으로 오셨어요"처럼 의도적으로 이메일 그 자체를 보여주는 곳(값 자체가 이메일이라는 걸 명시하는 라벨이 있거나, 온보딩 전이라 애초에 이름이 있을 수 없는 화면)은 이 형식 통일 대상이 아니다 — 계정을 "누구인지" 나타내는 일반 표시 위치만 바꾼다.
- [ ] 위 동작을 검증하는 자동화 테스트가 있다.

## 결정이 필요한 사항
없음.

## 범위 밖
- 문서별 "작성자"/"마지막 수정자" 표시는 이 항목 범위가 아니다 — 이 앱은 아직 계정별 개인 문서함 구조라 문서에 다른 사용자를 표시할 일이 없다. 페이지 공유(Phase 6, 특히 P6-7 마지막 수정자 표시)에서 그 형태의 표시가 새로 생기면 이 통일 규칙을 그때 적용한다.
