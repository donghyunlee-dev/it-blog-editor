# P19-7: 문서 이력 화면 상단에 문서 제목 표시

## 배경
사용자 지적 — "이력에 문서 제목이라도 표시를 해야 하는데, 이 문서의 이력이라고만 하니까
알 수가 없어. 상단에 이력을 보기로 한 문서의 제목을 표시해줘." `/editor/history/{pageId}`
화면(P19-1)이 "문서 이력"이라는 고정 문구만 보여줘, 여러 탭/문서를 오가며 쓸 때 지금 어느
문서의 이력을 보고 있는지 화면만으로 알 수 없었다.

## 수용 기준 (Acceptance Criteria)
- [x] `/editor/history/{pageId}` 화면 상단에 그 문서의 제목이 표시된다.
- [x] 제목이 비어 있으면(예외적인 경우) "(제목 없음)"으로 대체 표시한다(다른 화면과 깨짐
      없이 렌더링).

## 결정이 필요한 사항
없음 — `page.tsx`가 이미 P19-6(복원)을 위해 `getDocumentDetail`로 현재 제목을 조회해
`VersionHistoryPage`에 `currentTitle`로 내려주고 있어, 그 값을 그대로 화면에 표시하면 된다
(추가 API 호출 없음).

## 범위 밖
- 제목 클릭 시 편집 화면으로 이동하는 등의 추가 상호작용 — 이번엔 표시만 요청받았다.
