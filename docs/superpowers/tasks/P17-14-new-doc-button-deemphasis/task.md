# P17-14: "새 문서" 버튼 강조도 낮추기 — task

## 배경
- 외부(GPT) UI 개선 제안 리뷰 중 채택한 항목. 사용자가 제안 원문을 공유하며 "읽고 반영해도
  괜찮은 아이디어가 있는지 검토해서 작업 리스트 만들어줘"라고 요청했고, 이 채팅 세션에서
  실제 코드(`EditorSidebar.tsx`)와 대조 검토한 결과 진단이 정확한 것으로 확인된 항목이다.
- 문제: 사이드바 맨 아래 "새 문서" 버튼이 `bg-brand` 풀필드(브랜드 레드) 스타일이라, 이
  화면의 진짜 주 행위(문서함 탐색)보다 시각적으로 더 강한 무게를 갖는다.
- 폴더 "+"(폴더별 새 문서)와의 역할 분담(미분류 vs 폴더 지정)은 이미 올바르므로 그대로
  유지한다 — 이번 작업은 스타일(강조도)만 다룬다.
- 관련 코드: `src/components/editor/EditorSidebar.tsx` (하단 "새 문서" `<Link>`, P15-1/
  P15-4가 남긴 위치 결정 주석 참고).

## 수용 기준 (Acceptance Criteria)
- [x] 사이드바 하단 "새 문서" 링크가 더 이상 `bg-brand` 풀필드 스타일이 아니다.
- [x] `@sfood/ui`의 `Button variant="secondary"`가 실제로 쓰는 색 조합(`bg-surface
      border border-border text-foreground hover:bg-surface-raised`)과 동일한 강조도를
      갖는다 — 새 색상을 하드코딩하지 않고 기존 디자인 시스템 팔레트를 그대로 재사용한다.
- [x] href(`/editor/new`)·클릭 시 동작(`onNavigate`/`guardNavigate`를 통한 저장 안 된
      변경사항 경고)·위치(사이드바 스크롤 영역 밖, 맨 아래)는 그대로 유지한다 — 이번
      작업은 시각적 강조도만 바꾼다.
- [x] 폴더 "+"의 기존 툴팁(`title="이 폴더에 새 문서"`)은 이미 있으므로 손대지 않는다.

## 결정이 필요한 사항
없음 — 이미 이 코드베이스에 있는 `Button secondary` 변형의 색 조합을 그대로 재사용하는
스타일 변경이라 새로 정할 값이 없다.

## 범위 밖
- 폴더 "+" 버튼 스타일/위치 변경 — 이미 적절하다고 판단됨(그룹 hover로만 노출되는 아이콘
  버튼, 툴팁 존재).
- "미분류 새 문서"로 이름 변경 — 검토 결과 사용자에게 내부 데이터 구조(미분류 폴더 개념)를
  노출하는 셈이라 채택하지 않는다.
