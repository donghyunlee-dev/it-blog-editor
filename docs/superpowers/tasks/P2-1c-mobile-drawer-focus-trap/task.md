# P2-1c: 모바일 오프캔버스 드로어 포커스 트랩

## 배경
- 2026-08-27 [프로덕션 준비도 감사](https://claude.ai/code/artifact/87302c07-68d6-42ed-8712-9345547cb659)에서 발견된 접근성 공백 중 하나로, Phase 4의 P2-1c 항목이다(`docs/product/prd.md`의 "P2 — 다듬기" 체크리스트).
- `EditorShell.tsx`는 모바일(`isMobile`)에서 사이드바를 오프캔버스 드로어로 연다(`open` 상태, 햄버거 버튼으로 토글, 배경 오버레이 클릭으로 닫힘). 지금은 드로어가 열려도 포커스가 자동으로 그 안으로 들어가지 않고, Tab을 계속 누르면 포커스가 드로어를 벗어나 배경(뒤에 가려진 문서 편집 화면)의 요소로 넘어간다 — 시각적으로는 드로어에 가려 안 보이는 요소에 키보드 포커스가 가는, 전형적인 오프캔버스 드로어 포커스 누출 버그다.
- 이 프로젝트에 이미 같은 문제를 해결한 선례가 있다 — `GlobalSearchModal.tsx`(Ctrl+K 검색 팝업)가 `@sfood/ui`의 `Modal`이 내부적으로 하는 포커스 트랩·Escape 닫기·닫힐 때 포커스 복원을 직접 구현해 두고 있다(`docs/product/design.md` "Ctrl+K 검색 팝업" 절 참고). 이번 항목은 그 패턴을 모바일 드로어에 재현한다.
- **추가로 발견한 문제**: 모바일에서는 사이드바 안에 드로어를 닫는 키보드 접근 가능한 버튼이 하나도 없다(데스크톱 전용 "문서함 접기" 버튼은 `md:block`으로 모바일에서 숨겨져 있고, 닫는 방법은 배경 오버레이 클릭 또는 문서 링크 클릭뿐이다). 포커스 트랩만 추가하고 Escape 닫기를 빠뜨리면, 키보드 전용 사용자는 드로어 안에 그대로 갇혀 다른 문서로 이동하는 것 말고는 빠져나올 방법이 없어진다 — 그래서 이 항목은 포커스 트랩과 Escape 닫기를 한 세트로 다룬다.

## 수용 기준 (Acceptance Criteria)
- [ ] 모바일(`isMobile`)에서 드로어가 열리면(`open === true`) 포커스가 자동으로 드로어 안의 첫 번째 포커스 가능한 요소로 이동한다.
- [ ] 드로어가 열려있는 동안 Tab/Shift+Tab을 눌러도 포커스가 드로어 밖(배경의 가려진 문서 편집 화면)으로 나가지 않고 드로어 안에서만 순환한다.
- [ ] 드로어가 열려있는 동안 Escape를 누르면 드로어가 닫힌다.
- [ ] 드로어가 닫히면(Escape·배경 클릭·문서 링크 클릭 등 어떤 경로든) 열기 전 포커스가 있던 요소(대개 햄버거 버튼)로 포커스가 되돌아간다.
- [ ] 데스크톱(`!isMobile`)에서는 사이드바가 상시 표시되는 일반 패널이라 이 트랩이 전혀 개입하지 않는다 — 데스크톱에서 Tab은 평소처럼 사이드바를 거쳐 본문으로 자연스럽게 이어진다.
- [ ] 기존 배경 오버레이 클릭 닫기, 문서 링크 클릭 시 닫기(`onNavigate`) 동작은 그대로 유지된다.

## 결정이 필요한 사항
없음 — `GlobalSearchModal.tsx`가 이미 검증된 포커스 트랩 구현을 갖고 있어 그 패턴을 그대로 재현하면 된다.

## 범위 밖
- 슬래시 메뉴(P2-1a)·사이드바 리사이즈 핸들(P2-1b)은 이미 완료된 별개 항목이다.
- 배경 스크롤 잠금(`body.style.overflow`)은 `GlobalSearchModal`은 하고 있지만, 이 드로어는 이미 `position: fixed` 오프캔버스 패널 + 내부 스크롤 컨테이너 구조라 문서 body 자체가 스크롤되는 경로가 없다(코드로 확인) — 이번 항목(포커스 트랩)의 범위가 아니므로 추가하지 않는다.
- 드로어에 `role="dialog"`/`aria-modal`을 붙이는 것은 범위 밖으로 남긴다 — 같은 DOM 구조가 데스크톱에서는 상시 표시되는 일반 패널(모달이 아님)로도 쓰이므로, 정적으로 "항상 dialog"라고 표시하면 데스크톱 쪽 의미가 왜곡된다. 체크리스트 항목 자체도 "포커스 트랩"만 명시한다.
- 실제 스크린 리더·실제 모바일 기기로 직접 확인하는 수동 검증은 AX Auth 로그인 제약으로 하지 못한다 — jsdom 자동화 테스트로 포커스 이동·순환·복원을 검증한다.
