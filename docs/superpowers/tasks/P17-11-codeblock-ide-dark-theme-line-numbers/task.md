# P17-11: 코드 블록 IDE 스타일 다크 테마 + 줄 번호

## 배경
P17-5b(코드 블록 언어 선택 UI) PR을 리뷰하던 사용자 피드백: "일반 직원은 잘 안쓰겠지만,
코드 블록이라 하면 개발자가 IT 관련 사람이 사용하는데, 단순 회색 백그라운드 컴포넌트는
좀 별로야. 개발 코드라 하면 배경색상도 진한 다크톤이고, 라인 번호가 보이는 방식도 있을
수 있겠지. 약간 IDE의 느낌이 나면 좋지 않을까." 원래 Phase 17 목록(P17-1~P17-10)에는
없던 항목이다.

## 수용 기준 (Acceptance Criteria)
- [x] 코드 블록 배경이 앱의 라이트/다크 테마 선택과 무관하게 항상 어두운 톤(IDE 느낌)
      으로 보인다 — 라이트 테마에서 문서 본문은 밝은데 코드 블록만 어두운 패널처럼
      보이는 것이 의도된 결과다.
- [x] 코드 블록 안의 문법 강조(P1-7c)·언어 선택 드롭다운(P17-5b) 글자·테두리 색이
      두 테마 모두에서 배경과 충분한 대비로 정상적으로 읽힌다(회귀 없음 확인 — 최초
      구현 시 라이트 테마에서 드롭다운 글자가 배경과 같은 색이 되어 안 보이는 문제를
      발견해 같은 작업 중 수정했다).
- [x] 코드 블록 왼쪽에 줄 번호가 보인다. 코드가 몇 줄인지에 맞춰 순서대로 표시되고,
      줄이 추가/삭제되면 그 수도 함께 바뀐다.
- [x] 줄 번호는 편집 대상이 아니다(클릭/커서 이동/복사 대상에서 제외) — 코드 자체의
      ProseMirror 콘텐츠와는 분리된, 보기 전용 거터.
- [x] 커스텀 색상을 하드코딩하지 않는다 — `@sfood/ui`의 기본 팔레트 토큰
      (`tokens/base.css`의 `--gray-*`, 테마와 무관하게 고정)을 참조해 "항상 다크"를
      구현한다.

## 결정이 필요한 사항
없음 — 사용자가 "IDE 느낌"이라는 구체적인 방향과 "라인 번호"라는 구체적인 예시까지
제시했고, 색상은 이미 있는 디자인 시스템 기본 팔레트 토큰을 그대로 재사용하면 되므로
별도로 정할 값이 없다.

## 범위 밖
- 코드 블록 복사 버튼(P17-5c, 별도 작업 예정 — 이번에 만든 "코드 블록 안 UI는
  `.code-block-toolbar` 컨테이너 안에서 항상 다크 테마 토큰을 쓴다"는 패턴을 그대로
  재사용할 수 있다).
- 줄 번호 클릭으로 해당 줄 선택/하이라이트 같은 추가 IDE 기능(요청받지 않음).
- 긴 줄이 화면 폭을 넘을 때 줄 번호 거터가 코드와 함께 가로 스크롤되는 것(거터만
  고정하는 것)은 이번 범위 밖 — 구현이 더 복잡해지고 요청받지 않았다.
