# P15-3: 사이드바 "새 문서" 버튼을 스크롤 컨테이너 하단에 고정

## 배경
P15-1에서 "새 문서" 버튼을 문서/폴더 목록(`<nav>`) 맨 아래로 옮겼는데, 그 `<nav>` 자체가
스크롤 컨테이너다 — 문서가 많아 목록이 길어지면 이 버튼이 스크롤 맨 끝으로 밀려나 매번
스크롤해야만 보인다는 지적("새문서 버튼이 미분류 아래에 걸려 있는데, 문서 리스트가
길면 어떻게 되지?").

## 수용 기준 (Acceptance Criteria)
- [x] "새 문서" 버튼이 `<nav>` 스크롤 위치와 무관하게 항상 사이드바 하단에 보인다
      (`position: sticky; bottom: 0`).
- [x] 폴더 유무·문서 개수와 무관하게 기존 기능(미분류 문서 생성, `/editor/new`로 이동)은
      그대로 동작한다 — 위치만 고정될 뿐 href·동작 변경 없음.

## 결정이 필요한 사항
없음 — 사용자가 대화 중 방향(스크롤 컨테이너 안에서 sticky 고정)을 직접 확정했다.

## 범위 밖
- 이번 작업은 위치 이동(sticky 고정)과 새 문서 기능 자체까지만 다룬다 — 사용자 요청대로
  테스트도 그 범위(`EditorSidebar.test.tsx`)로 좁혔다.
