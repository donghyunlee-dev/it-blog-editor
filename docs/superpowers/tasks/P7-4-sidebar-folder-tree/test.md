## 수동 검증 (필요 시)
AX Auth 로그인 제약으로 실제 브라우저 확인은 하지 못했다(기존 UI 항목들과 동일한 제약). 자동화 테스트로 다음을 확인했다.
- 폴더가 없으면 기존 30건의 회귀 테스트가 전부 그대로 통과(마크업·동작 변경 없음).
- 폴더가 있으면 트리로 보이고, 미분류 문서는 "미분류" 레이블 아래 별도로 보인다.
- 폴더를 접으면 그 안 문서·하위 폴더가 숨고, 다시 펼치면 보인다.
- 하위 폴더는 상위 폴더보다 더 들여쓰기된다(`paddingLeft` 비교).
- 펼침/접힘 상태는 `localStorage`에 저장돼 재마운트 후에도 유지된다.
