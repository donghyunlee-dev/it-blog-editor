# P19-10: 문서 이력 화면 헤더 최종 정리(제목 위계 재조정 + 부제 제거)

## 배경
P19-8에서 "문서 이력"(화면 이름)을 작은 라벨로, 문서 제목을 큰 제목(h1)으로 바꿨는데,
사용자가 실제 화면을 보고 다시 지적 — "문서 이력 타이틀은 타이틀로 돌려놔. 지금은 일반
텍스트 사이즈니까 메뉴명같지 않아. 그 아래 제목을 살짝 여백을 줘서 잘 보이게 강조해줘.
이문서에 저장된 버전 이력입니다 라는 문구는 삭제해줘." 정리하면: (1) "문서 이력"은
화면 이름이니 다시 큰 제목으로, (2) 문서 제목은 그 아래 여백을 두고 눈에 띄게(작은 muted
라벨이 아니라) 보여주고, (3) 정보량이 적은 부제 문장은 제거.

## 수용 기준 (Acceptance Criteria)
- [x] "문서 이력"이 화면 제목(`h1`, 큰 글씨)으로 표시된다.
- [x] 문서 제목이 그 아래 여백을 두고, muted가 아닌 강조된 스타일로 표시된다.
- [x] "이 문서에 저장된 버전 이력입니다." 부제 문구는 제거한다.
