- `npx vitest run src/components/editor/EditorSidebar.test.tsx` — 71개 전부 통과.
  - 갱신한 테스트("문서 목록 행에는 태그를 표시하지 않는다"): 문서 목록 영역(`aria-label="문서 목록"`) 안에는 태그 텍스트("React"/"Backend")가 없고, 상단 태그 필터 칩(`role="tab"`)에는 여전히 있는지 검증.

## 수동/시각 검증
AX Auth 로그인 제약으로 이 세션에서는 실제 `/editor` 화면을 열어볼 수 없다(PRD의 기존 항목들과 동일한 한계). 다만 이번 변경의 계기 자체가 사용자가 실사용 화면(Phase 10 검증용으로 실제로 만든 노션 재현 문서 4개, 태그 2개씩)을 직접 보고 지적한 것이라, 변경 필요성 자체는 이미 실제 화면으로 확인된 상태였다. 코드 변경은 렌더링 블록을 제거하는 것뿐이라 회귀 위험이 낮다고 판단해 자동화 테스트만으로 충분하다고 봤다.
