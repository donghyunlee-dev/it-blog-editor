# P17-3: 표 툴바 행/열/표 삭제 아이콘 시각적 구분

## 배경
사용자 지적: "표(테이블) 툴바에 휴지통 아이콘이 여러 개 있어서 인식 불가."

조사 결과: `RichTextEditor.tsx`의 `TableToolbar`에서 "행 삭제"·"열 삭제"·"표 삭제" 버튼
셋 다 동일한 `TrashIcon` 컴포넌트를 그대로 재사용하고 있었다. `TableToolbarButton`이
`Tooltip`과 `aria-label`을 붙이긴 하지만, 이는 마우스를 올리거나 스크린리더를 써야만
구분되는 정보이고 아이콘 모양 자체는 셋이 완전히 동일했다.

## 수용 기준 (Acceptance Criteria)
- [x] "행 삭제" 버튼의 아이콘이 "열 삭제"·"표 삭제"와 시각적으로 다르다.
- [x] "열 삭제" 버튼의 아이콘이 "행 삭제"·"표 삭제"와 시각적으로 다르다.
- [x] "표 삭제" 버튼의 아이콘은 기존 범용 휴지통 모양을 유지한다(파괴성이 가장 크고
      유일하게 확인 Modal을 거치는 동작이라, "표 전체가 없어진다"는 기존 표현이 그대로
      적절하다는 판단).
- [x] 새 행/열 삭제 아이콘은 기존 삽입 아이콘들의 "가로줄=행 / 세로줄=열" 시각 문법을
      그대로 따라, 한 세트로 보였을 때 일관성이 있다.
- [x] 새 아이콘 라이브러리를 추가하지 않는다(design.md 선례 — `TableIcon`으로 직접 그린
      기존 SVG 관례를 그대로 따른다).
- [x] Tooltip·aria-label 등 기존 접근성 동작은 그대로 유지된다.

## 결정이 필요한 사항
없음 — 이미 확립된 아이콘 시각 문법(삽입 아이콘의 가로줄/세로줄 구분)을 그대로 확장하면
되고, 별도로 정할 값이 없다.

## 범위 밖
- 셀 병합/분할 아이콘 등 삭제와 무관한 나머지 툴바 아이콘 재검토(이번 지적은 삭제
  아이콘 3종에 한정됨).
- 표 행/열 삭제에도 확인 Modal을 추가할지 여부(P17-7에서 별도로 다룬다 — 이번 범위는
  아이콘 구분만).
