# P17-5c: 코드 블록 복사 버튼

## 배경
- PRD(`docs/product/prd.md`) Phase 17, P17-5c 항목: "코드 블록 복사 버튼 — 코드 블록에
  노드뷰를 추가해 클릭 한 번으로 코드 전체를 클립보드에 복사하는 버튼을 얹는다(복사
  성공/실패는 `Toast`)."
- 코드 블록에는 이미 P17-5b(언어 선택)·P17-11(IDE 다크 테마 + 줄 번호)로 노드뷰
  (`CodeBlockView`)와 툴바(`.code-block-toolbar`)가 있다 — 이 작업은 그 툴바에 복사
  버튼을 추가하는 것으로, 새 노드뷰 구조를 만들 필요는 없다.

## 수용 기준 (Acceptance Criteria)
- [x] 코드 블록 툴바(언어 선택 드롭다운 옆)에 복사 버튼이 보인다.
- [x] 버튼을 클릭하면 해당 코드 블록의 코드 전체 텍스트(`node.textContent`, 마크업 제외
      순수 텍스트)가 클립보드에 복사된다.
- [x] 복사 성공 시 `Toast`로 성공 안내가 뜬다.
- [x] 복사 실패(클립보드 API 예외) 시 `Toast`로 실패 안내가 뜬다.
- [x] 여러 코드 블록이 있을 때 각 블록의 복사 버튼은 자신의 코드만 복사한다(다른 블록에
      영향 없음).

## 결정이 필요한 사항
없음 — 버튼 위치(기존 툴바)·복사 대상(코드 텍스트 전체)·피드백 방식(Toast)이 PRD 항목
자체에 이미 명시돼 있어 추가로 정할 값이 없다.

## 범위 밖
- 복사한 코드에 문법 강조 마크업(HTML)을 함께 담는 것(리치 텍스트 붙여넣기 대상)은
  다루지 않는다 — 순수 텍스트 복사만 지원한다(대부분의 코드 에디터/터미널 붙여넣기
  대상과 호환되는 방식).
- 줄 번호를 복사 결과에 포함하지 않는다(거터는 표시용일 뿐 실제 콘텐츠가 아님 — P17-11).
