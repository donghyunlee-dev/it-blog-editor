# P8-6: 본문 최대 폭 조정

## 배경
support.claude.com/ko 벤치마킹(`docs/product/design.md` "벤치마킹" 절 "1. 전체 그리드")에서
레퍼런스의 본문 최대 폭이 830px로 실측됐다. 이 프로젝트는 `max-w-[820px]`(2026-08-26,
사내 문서 뷰어 SF-Note 실측 근거)로 10px 차이였다 — 판단 근거가 새로 필요 없는 사소한
차이라 GitHub Issue 없이 직접 830px로 맞추기로 정했다.

관련 PRD 항목: `docs/product/prd.md`의 **P8-6**(Phase 8, 에디터 UI 레이아웃 벤치마킹).

## 수용 기준 (Acceptance Criteria)
- [x] `DocumentEditor`의 본문 콘텐츠 컨테이너가 `max-w-[820px]` → `max-w-[830px]`로 바뀐다.
- [x] 기존 레이아웃(제목·태그·헤더)에 시각적 회귀가 없다 — 클래스 값만 바뀌고 다른 스타일은
      그대로다.
- [x] 회귀 테스트로 830px 클래스가 실제로 적용됨(그리고 옛 820px 클래스가 더는 없음)을
      고정한다.

## 결정이 필요한 사항
없음 — task.md 상단 배경에서 설명한 대로 10px 차이는 GitHub Issue 없이 직접 정할 수 있는
사소한 조정으로 이미 PRD(P8-6 항목 서술)에 그 근거가 명시돼 있다.

## 범위 밖
- 본문 리치 텍스트 타이포그래피 스케일(본문/H2/H3 폰트 크기) 변경 — P8-7의 몫이고, 이번
  Phase에서 바꾸지 않기로 이미 결정됨(design.md "6. 본문 리치 텍스트 타이포" 절 결론).
- 사이드바 폭·거터 등 다른 그리드 요소 변경(design.md "1. 전체 그리드" 표 — 이미 유사해
  불필요하다고 결론).
